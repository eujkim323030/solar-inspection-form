# 태양광 수검자 서식 (패드용 웹앱)

한국전기안전공사 「태양광발전설비 사용전 및 정기검사 수검자 서식」(서식자료실, 2026.01.05 개정)을
패드에서 칸 입력·체크·펜 필기로 채우고, 공식 양식 그대로 PDF로 내보내는 앱.

주소: https://eujkim323030.github.io/solar-inspection-form/

- `원본/` 공사 서식자료실에서 받은 원본 (서식 PDF·HWP, 점검기록표 작성방법 PDF)
- `tools/build.py` 원본 PDF → `docs/template.pdf`(예시값 지운 빈 양식), `docs/bg/*.png`(화면 배경), `docs/fields.json`(칸 좌표)
- `docs/` 배포하는 앱 (index.html 하나 + 오프라인 캐시 sw.js). GitHub Pages가 이 폴더를 내보낸다.

## 칸 좌표 다시 만들기

```
python -I tools/build.py 원본/1-1_수검자서식.pdf docs [디버그그림폴더]
```

디버그 폴더를 주면 쪽마다 잡힌 칸을 색칠한 그림이 나온다 (파랑=입력, 초록=자동채움, 빨강=체크).
칸 이름은 칸 왼쪽 위 좌표라서, 규칙을 고쳐 다시 만들어도 이미 적은 값이 다른 칸으로 밀리지 않는다.
공사가 서식을 개정하면 새 PDF로 다시 만들고 쪽 번호(`SHEETS`)를 확인한다.

## 배포

main 브랜치에 올리면 Pages가 `docs/`를 내보낸다. 올릴 때마다 `docs/sw.js`의 `VERSION`을 올려야 패드가 새 버전을 받는다.
데이터는 각 기기의 IndexedDB에 저장하고, 드라이브 연동을 켜면 구글 드라이브와 맞춘다.

## 드라이브 연동 (안전조회 앱과 같은 방식)

관리자 구글 계정의 Apps Script(`drive-sync.gs`)가 '내 드라이브 > 수검자서식 백업' 폴더를 공용 창고로 쓴다.
기기마다 처음 한 번 팀 코드를 넣으면 현장을 주고받고, 지운 현장은 '삭제됨' 폴더로 옮겨 보관한다.

1. script.google.com → 새 프로젝트 → `drive-sync.gs` 내용 붙여넣기 → `TEAM_CODE`를 원하는 코드로 바꾸고 저장
2. 배포 → 새 배포 → 웹 앱 → 실행: 나, 액세스: 모든 사용자 → 배포 → 권한 허용
3. 웹 앱 주소를 `docs/index.html`의 `SYNC_URL`에 넣고 `VERSION`을 올려 배포

`SYNC_URL`이 비어 있으면 연동 없이 그 기기에만 저장한다. 스크립트를 고치면 '배포 관리 → 수정 → 새 버전'으로 같은 주소를 유지한다.
